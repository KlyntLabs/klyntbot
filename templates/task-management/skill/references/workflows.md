# Task Management Workflows

## Daily Planning
1. List active tasks sorted by due date and priority
2. Consider energy level for task selection
3. Suggest "doing" status for tasks being worked on

## Task Decomposition
When a task is complex (multi-step or takes more than one sitting):
1. Create a parent task with the overall goal
2. Create subtasks linked via parent_id
3. Each subtask should be a single, clear action

## Weekly Review
1. List all tasks completed this week (status = done, updated this week)
2. List overdue tasks (due_date < today, status != done)
3. Review someday tasks for relevance
4. Suggest priority adjustments based on upcoming deadlines
