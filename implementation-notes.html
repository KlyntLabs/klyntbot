Pre-Execution Review Findings

Deviation (pre-emptive): ReforgeCollected does not derive Default in types.rs, but the plan assumes it does (Task 3 seed helper). I will add #[derive(Default)] to ReforgeCollected — it is a safe, behavior-neutral change for an internal collection struct.
Deviation (pre-emptive): ReviewOutput does not derive Default in types.rs (line 223). The plan's smoke test uses ReviewOutput::default(). I will add #[derive(Default)] to ReviewOutput.
Design decision: EpisodicMemoryRepo query method is list_by_domain(domain, limit) (not recent_by_domain as in the plan's Task 5 draft). I'll use the actual method name.
Design decision: For seeding collectable data in Task 6, the cheapest trigger is inserting a session via session_memory_repo.upsert(session_key, content, turn_count). The collector's skip gate is: !is_bootstrap && sessions.is_empty() && episodic_memories.is_empty(). Since bootstrap is false when last_run_at is Some (set by run_reforge), seeding one session memory makes Collect yield Some. However, session_memory.upsert requires a matching sessions row for FK. The test harness will insert a dummy sessions row first.
Tradeoff: The plan's seed_collectable helper is described as inserting via repo, but session_memory.upsert is simpler than constructing a full SessionMemoryRow with SqlTs. I'll use upsert in the harness helper.
