# DCF Valuation Guide

## Core Formula

DCF Value = Σ (FCFt / (1 + WACC)^t) + Terminal Value / (1 + WACC)^n

## Key Inputs

- **Free Cash Flow (FCF):** Operating cash flow minus capital expenditures
- **WACC:** Weighted average cost of capital (equity + debt blend)
- **Terminal Value:** Gordon Growth Model or Exit Multiple method
- **Projection Period:** Typically 5-10 years of explicit forecasts

## Common Pitfalls

- Over-optimistic revenue growth assumptions
- Ignoring working capital changes
- Terminal value dominating total valuation (>70% is a red flag)
- Using WACC that doesn't reflect actual capital structure
- Not performing sensitivity analysis on key assumptions

## Sensitivity Analysis Checklist

1. Revenue growth rate: ±2% from base case
2. WACC: ±1% from base case
3. Terminal growth rate: ±0.5% from base case
4. Operating margin: ±2% from base case
5. CapEx as % of revenue: ±1% from base case
