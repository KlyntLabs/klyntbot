# Personal Finance Guide

Manage accounts, transactions, budgets, investments, goals, and liabilities — all through chat.

## Getting Started

Tell klyntbot to set up your finances:

```
"Set up my finances"
"Add my bank account with 5,000,000 VND"
```

This creates your first account. From there, everything works through natural language.

## Everyday Use

### Transactions

```
"I spent 50,000 on lunch"
"Got paid 15,000,000 salary"
"Transfer 2,000,000 from bank to e-wallet"
"Add recurring rent 8,000,000 monthly"
```

### Budgets

```
"Create a monthly food budget of 3,000,000"
"Check my budget"
"How much food budget left?"
```

Budget alerts trigger automatically when you approach your limit.

### Reports

```
"How much did I spend this month?"
"Show my income this year"
"Spending trends"
"What's my net worth?"
```

## Investments

### Portfolios & Holdings

```
"Create a stock portfolio"
"Add 10 shares of AAPL at $190 each"
"What's my portfolio summary?"
"Bitcoin price"
```

### Investment Transactions

```
"Log a buy: 5 shares of MSFT at $420"
"Record dividend of $50 from AAPL"
```

## Goals & FIRE

```
"Create a savings goal: Emergency Fund, target 50,000,000"
"What's my FIRE number?"
"What if I save an extra 2,000,000 per month?"
```

## Liabilities

```
"Add credit card debt: 10,000,000 at 18% interest"
"List my liabilities"
"Update mortgage remaining to 500,000,000"
```

## Health Check

```
"Run a financial health check"
```

Scans for: missing accounts, negative balances, stale prices, duplicate budgets, overdue goals, and data issues.

## Daily Review

```
"Daily financial review"
```

Shows budget status, yesterday's top spending categories, and upcoming goal deadlines.

## Settings

```
"Show my finance settings"
"Set default currency to USD"
"Set proactivity to full"
```

**Proactivity levels:**
- **full** — daily reviews, budget alerts, price refreshes, in-chat nudges
- **moderate** — scheduled alerts only
- **reactive** — nothing automatic, you ask for everything

## Tips

- Amounts are in smallest currency unit (cents, dong). Say "$50" or "50,000 VND" — klyntbot converts automatically.
- No need to specify account IDs. If you have one account, it's used automatically.
- Ask "list accounts" or "list budgets" anytime to see what you have.
- All 37 actions are available. Just describe what you want in plain language.
